# 个人经验沉淀库

个人开发与工作经验的卡片化沉淀库。按项目组织，每个项目一个文件夹。

## 文件夹结构

每个项目文件夹固定三件套：

- `README.md` — 项目档案：概况、技术栈、状态、索引
- `想法与需求/` — 还没做的事：产品想法、需求、改进方向（**只记录，不规划**）
- `经验卡片/` — 已经发生的事：心得、踩坑、复盘

统一规范见 [IDEA.md](IDEA.md)。

## 日常用法

- 新增经验/想法：在对应项目的 `经验卡片/` 或 `想法与需求/` 下新建 `YYYY-MM-DD-标题.md`（可复制文件夹内的 `模板.md`）
- 本仓库由 Hermes 定时任务自动同步：每小时检查一次，有更新自动 commit + push
- 多设备管理：在任何设备改完，push / pull 即可保持同步

## 自动同步

由 Hermes cron 驱动，脚本：`~/.hermes/scripts/sync-experience-sedimentation.sh`

- 无更新 → 静默，不打扰
- 有更新 → 自动提交并推送，通知结果
- 推送失败 → 尝试拉取合并后重推（兼容多设备并发），仍失败则告警
