## 项目简介

面向个人工程造价师的 AI 驱动造价数据管理工具。把分散的历史 Excel 转化为**可检索、可比较、可追溯、可复用**的个人造价数据库。

- 用户：单人工程造价师，长期高频处理历史项目数据
- 核心主张：系统计算、规则匹配、AI 建议都展示依据，由用户确认关键结果，不替代专业决策
- 反参考：不做纯视觉导向的 AI 助手界面，不混排 AI 建议与原始数据

## 技术栈

| 层 | 选型 |
|---|---|
| 后端 | Python 3.13 / FastAPI / uv |
| 前端 | React / Vite / TypeScript / pnpm 10 |
| AI | DeepSeek 适配器（Key 存 macOS Keychain，不配置不影响导入/查询/匹配/指标/备份） |
| 数据 | `~/Library/Application Support/cost-data/` |
| 打包 | macOS arm64 onedir（`packaging/build-macos.sh`） |
