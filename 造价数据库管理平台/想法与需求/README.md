# 想法与需求收集

针对本项目的**产品想法、用户需求、改进方向**，统一收在这里。

与 `经验卡片/` 的分工：

| 文件夹 | 收什么 |
|---|---|
| `想法与需求/` | 还没做的事：想法、需求、改进方向、待决策的问题 |
| `经验卡片/` | 已经发生的事：心得、踩坑、复盘 |

## 用法

- **只记录**，不做任何关于未来方向的讨论：不展开实现方案、不拆任务、不排优先级推进
- 想到就记，一条想法一个文件，不追求一次写全
- 开发新功能前先翻这里，避免重复提想法、漏掉旧需求
- 状态字段跟踪生命周期：`想法 → 已采纳 → 已实现 / 放弃`，放弃的写明原因
- 命名：`YYYY-MM-DD-简短标题.md`
- 新卡片复制 [模板.md](模板.md)
