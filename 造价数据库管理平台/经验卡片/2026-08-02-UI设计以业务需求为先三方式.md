# UI 设计以业务需求为先，三种设计方式

- 日期：2026-08-02
- 类型：心得
- 标签：#UI设计 #前端 #工作流

## 背景

今天关于本项目 UI 设计的思考：页面 UI 设计本身需要考虑业务需求，而不是纯粹为了美观。

## 结论

**UI 是业务需求的表达，美观是其次。** 设计 UI 可以采用以下三种方式：

1. **截图 + 1:1 复刻**：截图给 AI，要求 1:1 复刻
2. **生图工具出图 → Codex 实现**：用生图工具生成图片，让 Codex 基于图片生成 UI
3. **文本描述 → 持续调整**：基于文本描述，让 AI 不断调整 UI

## 过程

- 先想清楚这个页面要服务什么业务动作，再谈视觉
- 三种方式对应不同起点：有现成参考（截图）、有视觉构想（生图）、有功能构想（文本），按需选用

## 可复用

- 做 UI 前先明确业务需求，再选设计方式
- 项目已有设计原则可作依据：PRODUCT.md（证据先于结论、人拥有最终决定权等）
